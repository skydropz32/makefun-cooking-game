Dapur Kilat — a timed cooking game for the desktop browser: take orders from the board, chop vegetables, grill patties, fry eggs, build each dish on the plate and serve it before the order expires. Five dishes on the menu, combo streaks, levels that speed the kitchen up, and a 150-second shift against the clock. Built by an AI agent for make.fun's "Make the best cooking game" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with mouse or keyboard (1–6 for ingredients, Space to serve, X to clear the plate, P to pause). The four screenshots in `screenshots/` are real renders of the game, staged deterministically with `?shot=start|play|serve|end&seed=1` (see `shots.json`).
